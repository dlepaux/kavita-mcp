# Code of conduct

Be respectful and inclusive. We are all here to build something useful together.

## Expected behaviour

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Accept constructive feedback gracefully.
- Focus on what is best for the people using the project.

## Unacceptable behaviour

- Harassment, discriminatory language or imagery.
- Trolling, insulting comments or personal attacks.
- Publishing others' private information without permission.
- Any conduct inappropriate in a professional setting.

## Reporting

Report unacceptable behaviour with GitHub's
[Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
option on the comment, issue or pull request concerned; it reaches the maintainer and GitHub. Every
report is reviewed promptly and fairly.
